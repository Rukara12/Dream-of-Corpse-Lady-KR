尸姬之梦 · The Dreamland of Lady Zombie

다운로드 명령어로 실행 GitHub Windows · Steam판
설치
  1. 1

    Dreamland-KR-Patch.exe를 내려받습니다.

  2. 2

    실행하면 게임 폴더를 자동으로 찾습니다. 못 찾으면 찾아보기로 지정합니다.

  3. 3

    설치를 누릅니다.

Windows의 PC 보호 창이 뜨면 자세히 → 실행을 누릅니다. 서명되지 않은 프로그램이 게임 파일을 수정하기 때문에 나타나는 경고입니다.
또는

명령어로 실행

curl.exe -L -o "$env:TEMP\KRPatch.exe" https://github.com/Rukara12/The-Dreamland-of-Lady-Zombie-KR/releases/download/latest/Dreamland-KR-Patch.exe; Start-Process "$env:TEMP\KRPatch.exe"

Win + X → 터미널 → 붙여넣기 → Enter

업데이트 후

패처를 다시 실행

스팀이 게임을 업데이트하면 패치가 원래대로 돌아갑니다. 패처를 다시 실행하면 됩니다.

원본은 게임 폴더의 한글패치_원본백업/에 보관됩니다.
